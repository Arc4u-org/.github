# Security policy

This policy applies to every public repository of the
[Arc4u-org](https://github.com/Arc4u-org) organisation that has no security policy of its own.
A repository's own `SECURITY.md` (for example the
[Arc4u framework's](https://github.com/Arc4u-org/Arc4u/blob/develop/9.0.0/SECURITY.md)) takes
precedence and lists its supported versions.

## Supported versions

Only released versions are supported, and only the latest release receives security fixes unless
the repository states otherwise. Preview versions (`x.y.z-previewNN`) and unreleased code are
published for evaluation only: they can change or be removed at any time and come with no support
commitment.

## Report a vulnerability

Do not report security vulnerabilities in public issues, pull requests or discussions.

Report them privately with GitHub's private vulnerability reporting: open the **Security** tab
of the affected repository and select **Report a vulnerability**. Include:

- the affected repository, packages and versions;
- a description of the vulnerability and its impact;
- the steps or a minimal reproduction to trigger it.

We aim to acknowledge a report within 5 working days and to send a first assessment within
15 working days, and we keep you informed until it is fixed. The fix is coordinated through a
GitHub security advisory, with a CVE requested where appropriate. Once the fix is published, the
advisory is made public and you are credited unless you ask not to be.
